# Аналитика Telegram/Instagram-активности мебельной индустрии Узбекистана

Интерактивный дашборд по 160 мебельным компаниям Ташкента: активность в Telegram и Instagram, качество исходных данных.

## Что внутри

- **`index.html`** — самодостаточный дашборд (HTML/CSS/JS, без сборки и внешних зависимостей). Открывается прямо в браузере или публикуется через GitHub Pages.
- **`data/companies_enriched.json`** — полный обогащённый датасет по всем 160 компаниям (сферы, ссылки на IG/TG, статус TG-канала, даты публикаций).
- **`data/dashboard_data.json`** — тот же датасет в облегчённой форме, встроен внутрь `index.html`.
- **`data/tg_channel_meta.json`** — метаданные 75 уникальных Telegram-каналов (название, число подписчиков, тематика, признак принадлежности к мебельной отрасли), собранные через публичные превью-страницы `t.me/s/<канал>`.

## Источник данных

Исходная выгрузка — файл `Аналитика Мебель.xlsx` (160 строк, собран 13.08.2026): название компании, сфера деятельности, ссылки на Instagram/Telegram/Facebook/2GIS, дата последней публикации в Telegram, дата публикации до 01.09.2025 (для сравнения активности год назад).

## ⚠️ Важная оговорка по качеству данных

При анализе обнаружилось, что многие ссылки на Telegram в исходном файле ведут **не на собственные каналы компаний**, а на сторонние каналы: доски вакансий (hh.uz, Биржа.Уз), банки, СМИ, госструктуры, маркетплейсы и т. д. — вероятно, из-за автоматического сбора данных по ключевым словам/упоминаниям.

Дашборд классифицирует каждую TG-ссылку на 4 типа (проверено вручную + через анализ содержимого канала):

| Статус | Кол-во | Описание |
|---|---|---|
| `own_brand_channel` | 24 (15%) | Похоже на собственный канал бренда |
| `shared_furniture_channel` | 29 (18%) | Общий отраслевой канал (мебельный комплекс, ассоциация, поставщик комплектующих), используемый несколькими компаниями |
| `unrelated_channel` | 73 (46%) | Ссылка ведёт на канал, не связанный с мебелью вообще |
| `no_telegram` | 34 (21%) | Ссылки на Telegram нет |

Показатели давности постов и подписчиков в дашборде считаются **только по `own_brand_channel`**, чтобы не завышать реальную активность рынка в Telegram; показатель «TG-присутствие» дополнительно включает `shared_furniture_channel`.

## Ключевые находки

- **Instagram — основной канал коммуникации отрасли**: 96% компаний имеют активный Instagram, тогда как подлинный собственный Telegram-канал — лишь у 15%.
- **Каждая вторая TG-ссылка в исходных данных нерелевантна** — это самостоятельная находка о качестве данных, а не о низкой активности бизнеса.
- Среди компаний с собственным TG-каналом больше половины (12 из 24) публиковали посты за последние 7 дней — то есть если канал есть, он, как правило, активно ведётся.
- Медианный размер собственного канала — ~1500 подписчиков; лидеры — Istiqbol Ideal Mebel, EMAN Materials, Muborak Mebel Fabrikasi.

## Фильтры

Фильтры по сфере деятельности (чипы), статусу TG-присутствия (выпадающий список) и поиск по названию компании — применяются ко всем графикам и плиткам одновременно.

## Как открыть

Просто откройте `index.html` в браузере — интернет не требуется, все данные встроены в файл.

Чтобы опубликовать как сайт через GitHub Pages: Settings → Pages → Source: `main` / root, после чего дашборд будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Как обновить данные

1. Обновите `Аналитика Мебель.xlsx` (или получите новую выгрузку).
2. Пересоберите `data/companies_enriched.json` (структура и логика классификации TG-ссылок — см. историю коммитов/скрипты обработки; при необходимости повторите сбор `tg_channel_meta.json` через публичные страницы `t.me/s/<канал>` для новых каналов).
3. Обновите встроенный JSON внутри `index.html` (блок `<script id="raw-data" type="application/json">`).
